# Chann CRM AI — ความครบถ้วนเทียบ CRM ในตลาด (2 ก.ย. 2569)

เอกสารนี้ตอบคำถามเจ้าของโปรเจกต์ตรงๆ: "ครบตามแบบที่ระบบ CRM ในตลาดมีไหม"
อ้างอิงจากสามแหล่งที่ตรวจได้จริง — `scripts/dev/check-parity.py` (ความเท่ากัน
แชท↔UI), การใช้งานจริงทั้งวัน 2 ก.ย. (จอทุกใบที่รายงานเข้ามา), และ Master
Spec — ไม่ใช่จากความรู้สึก คอลัมน์สถานะ: ✅ ครบทั้งแชท+UI · 💬 แชทเท่านั้น ·
🖥 UI เท่านั้น · ⛔ ยังไม่มี

## แกนที่ CRM ตลาด (HubSpot/Pipedrive/Zoho ระดับ SMB) ถือเป็นพื้นฐาน

| ความสามารถ | สถานะ | หมายเหตุ |
|---|---|---|
| ลูกค้า: สร้าง/ดู/แก้/ค้นหา/dedup เบอร์ | ✅ | dedup หนึ่งเบอร์หนึ่งลูกค้าอยู่ใน data tier |
| Lead → Customer (promote) | ✅ | |
| ดีล + pipeline stage + เหตุผลแพ้ | ✅ | Kanban board ยังไม่มี — UI เป็น list (ตลาดมี board ลาก-วางเกือบทุกเจ้า) |
| นัดหมาย/กิจกรรม: สร้าง/เลื่อน/เสร็จ/ยกเลิก | ✅ | เพิ่งครบสัปดาห์นี้ทั้งสองฝั่ง |
| บันทึก (notes): เพิ่ม/แก้/ลบ | ✅ | เพิ่งครบสัปดาห์นี้ |
| ใบเสนอราคา + PDF + ส่วนลด/VAT/valid_until | ✅ | แก้ได้เฉพาะ draft (ถูกต้อง และตอนนี้บอกเหตุผลแล้ว) |
| สินค้า (catalogue) | 💬+🖥 บางส่วน | UI upsert ได้แต่**ลบไม่ได้** (backlog ใน checker) |
| งานช่าง (tickets): สร้าง/รับงาน/มอบหมาย/ปิด | ✅ บางส่วน | ลูกค้าแจ้งซ่อม + ช่างรับงานได้บน UI แล้ว (3 ก.ย.); มอบหมาย/ปิดจากแดชบอร์ดยังไม่มี |
| Check-in/out หน้างาน + GPS | ✅ | check-out = ส่ง service report ในจังหวะเดียว บนแดชบอร์ดช่าง (3 ก.ย.) |
| รายงานยอด/สรุป | 💬+🖥 | มีทั้งสองแบบแยกกัน ยังไม่ได้ audit ว่าตัวเลขชุดเดียวกัน |
| รับประกัน: ลงทะเบียน/ดูของตัวเอง | ✅ | แดชบอร์ดลูกค้า (3 ก.ย.); แก้ไขยังเป็นงานเจ้าหน้าที่ผ่านแชท |
| สิทธิ์/บทบาท/ทีม | ✅ | |
| Audit log | ✅ | |
| แจ้งเตือนอัตโนมัติ (digest เช้า) | ✅ | policy เจ้าของ: บอกเฉพาะงานที่ยังไม่ถึง |

## ที่ตลาดมีแล้วเรายังไม่มี (เรียงตามที่ Sale จะรู้สึกก่อน)

1. **⛔ ค้นหากลาง (global search)** — ตลาดทุกเจ้ามีช่องเดียวพิมพ์อะไรก็เจอ
   ของเราค้นได้เป็นชนิดๆ ("ค้นหาลูกค้า...") แชทช่วยกลบจุดนี้ได้เยอะแต่ UI
   ไม่มีเลย
2. **⛔ Import/Export CSV** — ลูกค้าจริงย้ายมาจาก Excel เสมอ ไม่มีทางเข้า
   ข้อมูลเก่านอกจากพิมพ์ทีละราย และไม่มีทางออกไปทำอย่างอื่นต่อ
3. **🖥→⛔ Kanban pipeline board** — ดีลเป็น list; ภาพรวม pipeline แบบลากการ์ด
   คือหน้าจอหลักของ Pipedrive/HubSpot
4. **⛔ กิจกรรมย้อนหลังรวมเส้นเดียว (timeline)** — ตอนนี้ นัดหมาย/บันทึก/audit
   แยกสามกอง ตลาดรวมเป็น timeline เดียวต่อลูกค้า
5. **⛔ มอบหมาย/โอนลูกค้าระหว่าง Sale** — มี transfer request ใน route แล้ว
   แต่ยังไม่โผล่ทั้งแชทและ UI อย่างครบวงจร (ต้อง audit แยก)
6. **⛔ Email/แนบไฟล์กับลูกค้า** — LINE-first เป็นจุดขายของเรา แต่แนบรูป/ไฟล์
   เข้า record ยังไม่มี (ช่างถ่ายรูปหน้างาน → ตอนนี้ไปอยู่ใน service report
   เท่านั้น)

## สิ่งที่เราทำได้เหนือตลาด (อย่าทำหาย)

- สั่งงานภาษาไทยธรรมชาติผ่าน LINE — ตั้งนัด/แก้บันทึก/ออกใบเสนอราคา จบใน
  ประโยคเดียว โดยเข้าใจบริบท "ลูกค้าที่เพิ่งคุยถึง" และ reply ข้อความเก่าได้
- Digest เช้าแบบ opinionated (ไม่สแปม ไม่โกหกเรื่องวันที่)
- Audit ทุกการแก้พร้อมข้อความเดิม (note edit เก็บของเก่า)

## ลำดับที่เสนอ (ให้เจ้าของตัดสิน)

1. **Tickets บน UI** (create/assign/close/update + check-out route) — ปิด
   backlog ของ checker ทั้งกอง และเป็นงานที่ Sale+ช่างเจอทุกวัน
2. **Global search** ใน UI (ต่อยอด endpoint ค้นหาที่มีอยู่รายชนิด)
3. **Import CSV ลูกค้า** (dedup เบอร์มีอยู่แล้ว — งานหลักคือหน้าจอ+ validation)
4. Kanban board / timeline — ชิ้นโต ทำเมื่อสามข้อบนเสถียร

เอกสารนี้ควรอัปเดตทุกครั้งที่ backlog ใน `check-parity.py` เปลี่ยน — สอง
ที่นี้ต้องเล่าเรื่องเดียวกันเสมอ
