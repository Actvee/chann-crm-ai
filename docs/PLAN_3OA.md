# แผนงาน 3 OA — เรียงใหม่จาก Master Spec (3 ก.ย. 2569)

เจ้าของสั่ง (3 ก.ย. เย็น): "ลองดู Phase ใน master spec ที่เกี่ยวข้องกับงานที่ทำอยู่
ทั้งหมด แล้วเรียง Phase ใหม่ เอางานที่เกี่ยวกับ 3 OA นี้มาทำทั้งหมด" และ "นำ Phase 16
มาร่วมดูและทำด้วย" · ไม่ต้องทำใบรับประกัน PDF · **Service Report PDF ต้องมี** (แก้ 3 ก.ย. ค่ำ)

หลักการเรียง: **ทางเดินของงานซ่อมก่อน** (ลูกค้าแจ้ง → CS มอบหมาย → ช่างรับ/ปฏิเสธ →
เช็คอิน → ปิดงาน+รายงาน → CS อนุมัติ → ลูกค้าประเมิน) เพราะทุกอย่างในระบบพิสูจน์ได้
ก็ต่อเมื่อเดินสายนี้ได้จริงกับ OA จริง จากนั้นค่อยเป็นสิ่งที่ทำให้ 3 OA "ครบ" ตาม
spec (ทีม, ภาษา, ค้นสินค้า, คุยกับร้าน) แล้วปิดด้วย polish

สถานะใช้คำของ playbook: PROVEN (เดินกับ OA จริงแล้ว) · CODE_COMPLETE (มีโค้ด
+ เทสต์ + deploy แล้ว รอเดินจริง) · PARTIAL · NOT_STARTED · DEFERRED

## B. งานที่เหลือของ 3 OA — เรียงตามลำดับที่จะทำ

1. ~~Sale dashboard: มอบหมาย/แก้/ยกเลิก ticket จากหน้าจอ~~ — **ทำแล้ว** (`dispatch-ui-v1`,
   3 ก.ย. ค่ำ): มอบหมายให้ช่าง/ทีมผ่าน gate เดิม + แจ้งช่างทาง LINE, แก้ชื่อ/เบอร์/ที่อยู่/นัด/S/N,
   ยกเลิกพร้อมแจ้งช่าง
2. **ทีมช่างตาม 12.4 เต็มรูป** — หัวหน้าทีมรับแทนทีม (`accept_status=team_accepted`
   ต้อง migration) → เปิด public ในทีม → สมาชิกรับ; ปฏิเสธโดยหัวหน้า → CS · ขนาด: กลาง (มี migration)
3. **รูปหลักฐาน + ลายเซ็น (Phase 13.1, 13.5)** — ส่งรูปใน LINE ตอนเช็คอิน/ปิดงาน →
   GCS → `ticket_photos`; ลายเซ็นผู้อนุมัติผูก identity · ขนาด: กลาง-ใหญ่ (GCS upload
   จาก LINE content API)
4. **Phase 16 ให้ครบ** — 16.1 ค้น serial ข้ามร้าน + auto-create ลูกค้าเมื่อ
   `auto_accept_new_customers` (ตรวจว่า setting นี้มีผลจริงกับ flow ผูกร้าน) + audit ทุก
   cross-tenant lookup (มีแล้ว ตรวจซ้ำ) · 16.3 display preference: ภาษาทำแล้ว
   (`tech-flow-v1`), เพิ่มรูปแบบวันที่/timezone ใน UI + ใช้ในข้อความ · ขนาด: เล็ก
5. **Customer OA ตาม spec หน้า 1–2** — ค้นหาสินค้า/สินค้าทั้งหมด (Phase 9 storefront มีใน
   แชท; home ยังไม่มี), ประวัติ/คำสั่งซื้อ, ใบรับประกันทั้งหมด (มี), ปุ่มสลับภาษา (16.3 ทำแล้ว
   ในโปรไฟล์) · ขนาด: กลาง
6. **Phase 15 Live Chat "คุยกับร้าน" + SLA** — session, dashboard ตอบ, push กลับ CS OA,
   หยุด auto-create ระหว่าง session, SLA/escalate/timeout · ขนาด: ใหญ่ (2 ตาราง + migration)
   · ตอนนี้ "ติดต่อร้าน" = ส่งข้อความให้ร้านเห็นเท่านั้น
7. **Rich menu หน้าที่ 2 ต่อ OA (Phase 19)** — เมื่อ 5–6 ขึ้นแล้วเมนู 6 ช่องไม่พอ
8. **Phase 20 polish** — i18n EN ให้ครบทุกข้อความบอท/notification (ตอนนี้ EN มีแต่
   ข้อความหลัก), loading/error state, accessibility pass ซ้ำ, ปิดด้วย evidence
   ทุก phase
