# สิทธิ์การใช้งาน — คู่มือสำหรับเจ้าของร้าน

สิทธิ์ตั้งได้ที่แดชบอร์ด Sale > บทบาทและทีม (ต้องมีสิทธิ์ «จัดการบทบาท») เมื่อพนักงานพิมพ์คำสั่งที่ไม่มีสิทธิ์ ระบบจะบอกชื่อสิทธิ์ที่ต้องขอ ตามชื่อในตารางนี้

[IMAGE: permissions-overview — หน้าจอ 'บทบาทและทีม' ธีมเขียว แสดงบทบาท เจ้าของ / CS / ขาย / ช่าง และ toggle สิทธิ์เป็นหมวด ลูกค้า ดีล งานซ่อม รายงาน]
